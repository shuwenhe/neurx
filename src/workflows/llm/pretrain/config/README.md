# Pretrain Config

Place small run presets and parameter sets here.

`sample.yaml` is the lightweight debug preset.

`gpt55_reference.yaml` is a reference-only modern GPT-style dense pretraining preset:

- It is meant to resemble contemporary large autoregressive training practice.
- It is not an official GPT-5.5 architecture or OpenAI training recipe.
- Adjust the distributed degrees and batch sizing to match your cluster before launch.
