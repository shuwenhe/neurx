## 🎓 训练架构说明

### Layer 1: Loss 函数层
```
Softmax → 归一化概率分布
CrossEntropy → 计算损失值
Perplexity → 计算困惑度
```

### Layer 2: Attention 层
```
Multi-Head Attention → 序列建模
隐藏状态聚合 → 特征提取
```

### Layer 3: 训练循环层
```
数据生成 → 批处理
前向传播 → 损失计算
学习率调整 → 优化控制
```
