## 2. 前向传播流程

```
输入数据 (Input Batch)
    │
    ▼
┌─────────────────────────────────────┐
│  第一层: Linear/Conv2d/Embedding    │
│  output = weight @ input + bias      │
└────────────┬────────────────────────┘
             │
             ▼
┌─────────────────────────────────────┐
│  激活函数: ReLU/Tanh/Sigmoid        │
│  activated = activation(output)      │
└────────────┬────────────────────────┘
             │
             ▼
┌─────────────────────────────────────┐
│  Batch Normalization (可选)         │
│  normalized = batchnorm(activated)   │
└────────────┬────────────────────────┘
             │
             ▼
┌─────────────────────────────────────┐
│  Dropout (训练时)                    │
│  dropped = dropout(normalized)       │
└────────────┬────────────────────────┘
             │
             ▼
         (中间层重复)
             │
             ▼
┌─────────────────────────────────────┐
│  输出层: Linear                      │
│  output = weight @ input + bias      │
└────────────┬────────────────────────┘
             │
             ▼
        最终输出 (Output)
```

## 3. 反向传播 (BackPropagation) 流程

```
损失函数计算
    │
    ▼
┌──────────────────────────────┐
│ Loss = criterion(pred, true) │
└────────┬─────────────────────┘
         │
         ▼
┌──────────────────────────────────┐
│ 从输出层向后逐层计算梯度          │
│ dL/d(output) 已知              │
└────────┬─────────────────────────┘
         │
         ▼
┌──────────────────────────────────┐
│ 计算每个参数的梯度               │
│ param.grad = dL/d(param)        │
│ (使用链式法则)                   │
└────────┬─────────────────────────┘
         │
         ▼
┌──────────────────────────────────┐
│ 梯度累积到各层的 .grad 属性      │
└────────┬─────────────────────────┘
         │
         ▼
┌──────────────────────────────────┐
│ 优化器根据梯度更新参数            │
│ param = param - lr * param.grad   │
└────────┬─────────────────────────┘
         │
         ▼
┌──────────────────────────────────┐
│ 清空梯度为下一次迭代做准备        │
│ optimizer.zero_grad()            │
└──────────────────────────────────┘
```

## 6. GPU加速流程

```
模型和数据转移
    │
    ├─ 模型转GPU:
    │  model = model.to('cuda')
    │  或 model.cuda()
    │
    ├─ 数据转GPU:
    │  inputs = inputs.to('cuda')
    │  targets = targets.to('cuda')
    │
    └─ 自动混合精度 (AMP):
       with torch.cuda.amp.autocast():
           outputs = model(inputs)
           loss = criterion(outputs, targets)

       scaler.scale(loss).backward()
       scaler.step(optimizer)
       scaler.update()
           │
           ▼
┌─────────────────────────────┐
│  GPU内存优化                 │
│  - Gradient Checkpointing   │
│  - Distributed DataParallel │
│  - Model Parallelism        │
└─────────────────────────────┘
```


## 9. 常见操作速查表

| 操作 | 代码示例 |
|------|---------|
| 模型训练模式 | `model.train()` |
| 模型评估模式 | `model.eval()` |
| 禁用梯度计算 | `with torch.no_grad():` |
| 启用梯度跟踪 | `input.requires_grad_(True)` |
| 获取模型参数 | `model.parameters()` |
| 获取梯度 | `param.grad` |
| 清空梯度 | `optimizer.zero_grad()` |
| 保存模型 | `torch.save(model.state_dict(), 'model.pth')` |
| 加载模型 | `model.load_state_dict(torch.load('model.pth'))` |
| GPU转移 | `model.to('cuda')` 或 `model.cuda()` |
