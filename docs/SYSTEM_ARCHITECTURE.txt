SCALING EFFICIENCY:

Single GPU:              1 GPU × Throughput
Data Parallel (DDP):     8 GPU × 90% efficiency = 7.2x speedup
Tensor Parallel (TP):    8 GPU × 85% efficiency = 6.8x speedup
Hybrid (DP+TP):          64 GPU × 85% efficiency = 54x speedup

MEMORY USAGE:

Per-GPU Memory = Model Size + Optimizer State + Activations + Gradients

With ZeRO Stage 2:
Stage 1 only (batch 1): 80 GB per GPU → 40 GB per GPU (2x reduction)
Stage 1+2 (batch 1):    80 GB per GPU → 20 GB per GPU (4x reduction)
Stage 1+2+3 (batch 1):  80 GB per GPU → 10 GB per GPU (8x reduction)

With Gradient Checkpointing:
Reduces activation memory from 80% to 20% of total

THROUGHPUT:

Single GPU (A100):       2,500-3,500 tokens/sec
8 GPU DDP (A100):        20,000-24,000 tokens/sec
64 GPU (A100):           120,000-160,000 tokens/sec (with optimization)

TIME TO TRAIN 100K STEPS:

1B Model:                ~2 days (1 GPU)
7B Model:                ~10 days (1 GPU), ~1 day (8 GPU)
70B Model:               ~14 days (8 GPU TP), ~7 days (16 GPU hybrid)
200B Model:              ~14 days (64 GPU hybrid)
