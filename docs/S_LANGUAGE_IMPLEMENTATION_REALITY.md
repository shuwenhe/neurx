## 🔧 为什么 S 语言不适合 ML

1. **缺乏系统库**
   - 无标准 I/O（文件、网络）
   - 无内存管理工具
   - 无第三方库生态

2. **没有 GPU 支持**
   - S 主要用于分布式系统
   - 没有 CUDA/ROCm 绑定
   - 适合编排，不适合计算

3. **开发效率低**
   - 需要手写所有数学函数
   - 编译器缺少优化
   - 调试工具有限

4. **运行时限制**
   - 没有实现完整的标准库
   - 当前 S 运行时是示例实现

## 💡 为什么还要在 S 中实现？

### 优点：
1. **架构演示** - 展示了如何在受限环境中组织 ML 代码
2. **学习价值** - 理解神经网络的数学基础
3. **实验框架** - 为 NeurX 框架提供参考实现
4. **模块化设计** - 库可以在其他语言中重用

### 限制：
1. **不可用于实际训练** - 缺少关键基础设施
2. **性能不可接受** - 没有硬件加速
3. **开发成本很高** - 大量重复造轮子
