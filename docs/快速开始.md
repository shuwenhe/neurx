## 📝 Data样例

**Original MedMCQA Format:**
```json
{
  "question": "Chronic urethral obstruction...",
  "opa": "Hyperplasia",
  "opb": "Hyperophy",
  "opc": "Atrophy",
  "opd": "Dyplasia",
  "cop": 3,
  "exp": "Chronic urethral obstruction because of..."
}
```

**Convertafter SFT Format:**
```json
{
  "instruction": "Answer the following medical multiple-choice question accurately.",
  "input": "Chronic urethral obstruction...\n\nOptions:\nA) Hyperplasia\nB) Hyperophy\nC) Atrophy\nD) Dyplasia",
  "output": "Answer: D\n\nExplanation: Chronic urethral obstruction because of..."
}
```
