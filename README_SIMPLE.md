# NeurX 使用说明 - 3分钟速成

## 🎯 核心：只需要 1 个文件 + 1 个命令

### 文件
```
posttrain/trainer/posttrain_main.s
```
这是**唯一**需要编辑的文件。

### 命令  
```bash
make posttrain
```
这会运行训练（约8秒）。

---

## ✅ 如何验证训练工作？

运行后看最后几行：
```
modules[0].lora_A[0] = 0.00001999    # 权重变了
modules[0].lora_B[0] = 0.00001008    # 权重变了  
loss=29.414998                        # Loss有值
```

如果看到这些，**训练就是真的在工作**。

---

## 🔧 常见修改

打开 `posttrain_main.s`，找到这些行：

| 修改目标 | 行号 | 示例 |
|---------|------|------|
| 训练轮数 | 209 | `int epochs = 3` |
| 样本数 | 210 | `int samples_per_epoch = 5` |
| 学习率 | 212 | `float effective_lr = 0.1` |

改完后运行：
```bash
make posttrain
```
