## Performance Characteristics

### scatter_add
- **Time**: O(B × N) where B = batch size, N = number of indices
- **Space**: O(output_size) - creates full copy
- **Optimization**: Candidate for CUDA kernel (10-100x speedup potential)

### meshgrid
- **Time**: O(∏ dim_sizes) - proportional to output
- **Space**: O(∏ dim_sizes) per output grid
- **Optimization**: Uses numpy broadcasting efficiently
