# NeurX Documentation

当前主线以 `S` 为准，不再保留旧打包、测试和示例入口。

当前文档保留最小的 `S` 入口信息：

- 使用 `make s-compile-runtime` 生成 IR。
- 使用 `s train/loop.s` 启动训练原型。
- 使用 `s serving/serve/serve.s` 启动服务原型。
- 使用 `README.md` 与 `DIR_REORG_PLAN.md` 了解当前框架分层。
- 使用 `CODE_AGENT_ACTION_SCHEMA.md` 了解 code agent 动作协议。
- 使用 `CODE_AGENT_REFERENCE_MAP.md` 了解当前 code agent 主参考项目与目录映射。
- 使用 `CODEX_CLAUDE_CODE_PARITY_PLAN.md` 了解对标 Codex / Claude Code 还缺哪些能力以及应按什么顺序补齐。
- 使用 `LOCAL_CODE_AGENT_EXECUTION_PLAN.md` 作为当前本地 coding agent 主线执行文档。
