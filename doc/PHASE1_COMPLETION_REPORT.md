**数值稳定性对比**：

```python
x = 1e-7
# 不稳定方式

```

**梯度验证**：
```python
x = neurx.Tensor([0.1, 0.5, 1.0], requires_grad=True)
y = x.log1p().sum()
y.backward()
# x.grad 正确计算为 1/(1+x) = [0.909..., 0.666..., 0.5]
```

### ✅ 4. 逻辑运算 (2个)

| 方法 | 功能 | 返回类型 | 支持维度缩减 |
|-----|------|--------|-----------|
| `all(dim)` | 全为真检查 | Boolean | ✅ |
| `any(dim)` | 任一为真检查 | Boolean | ✅ |

**特性**：
- 支持按维度归约
- 保持维度选项 (`keepdim`)
- 返回float32张量便于后续计算

**示例**：
```python
x = neurx.Tensor([[1.0, 2.0], [0.0, 1.0]])

# 全为真
x.all()  # 返回 0.0 (有0存在)

# 按行检查
x.any(dim=1)  # [1.0, 1.0] (每行至少有非零)

# 按列检查
x.all(dim=0)  # [0.0, 1.0] (第一列有0)
```

### 高级使用场景

```python
# 优化器更新步骤
def update_weights(weights, grads, lr=0.01):
    # In-place 操作优化内存使用
    grads.clamp_(-1.0, 1.0)  # 梯度裁剪
    weights.sub_(grads * lr)  # 权重更新

# 数值稳定的概率计算
def log_softmax_stable(logits):
    logits_shifted = logits - logits.max(dim=-1, keepdim=True)[0]
    # 使用 log1p 提高稳定性
    return logits_shifted - logits_shifted.exp().sum().log1p()
```
