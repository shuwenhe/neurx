                           🔧 集成指南
================================================================================

【方式1: 直接替换】
cp -r python/neurx/core/* /path/to/neurx/core/
更新 __init__.py 导入

【方式2: 分阶段集成】
1. 先集成张量创建 (tensor_creation.py)
2. 然后集成索引操作 (tensor_indexing.py)
3. 接着集成统计 (tensor_stats.py)
4. 最后集成线性代数 (linalg.py)

【方式3: 模块可选导入】
# 仅导入需要的功能
from neurx.core.tensor_creation import zeros, ones
from neurx.core.linalg import inv, det
