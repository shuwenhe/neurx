# 🚀 NeurX 2-Node 分布式推理 - 快速部署卡

## 三句话总结

> 在 Controller (192.168.10.39) 上运行 `NEURX_ROLE=controller bash deploy.sh`
> 
> 在 Worker (192.168.10.75) 上运行 `NEURX_ROLE=worker bash deploy.sh`
> 
> 验证集群状态并测试推理 ✅

## 🎯 3 步部署

### 1️⃣ Controller 上启动

**在 192.168.10.39 上**：

```bash
ssh shuwen@192.168.10.39
cd ~/neurx
NEURX_ROLE=controller bash config/clusters/2node_deployment/deploy.sh
```

**保持这个窗口打开** ✋

---

### 2️⃣ Worker 上启动

**在新窗口中连接 192.168.10.75**：

**保持这个窗口打开** ✋

## 🔗 关键命令集

### 启动

```bash
# Controller
ssh shuwen@192.168.10.39 'cd ~/neurx && NEURX_ROLE=controller bash config/clusters/2node_deployment/deploy.sh'

# Worker
ssh shuwen@192.168.10.75 'cd ~/neurx && NEURX_ROLE=worker bash config/clusters/2node_deployment/deploy.sh'
```

### 监控

```bash
# 集群状态
bash ~/neurx/config/clusters/2node_deployment/monitor.sh

# 实时日志
ssh shuwen@192.168.10.39 'tail -f /tmp/neurx_cluster/logs/*.log'
ssh shuwen@192.168.10.75 'tail -f /tmp/neurx_cluster/logs/*.log'

# 心跳检查
ssh shuwen@192.168.10.39 'ls -la /tmp/neurx_cluster/heartbeat/'
ssh shuwen@192.168.10.75 'ls -la /tmp/neurx_cluster/heartbeat/'
```

### 测试

```bash
# 模型列表
curl http://192.168.10.39:8000/v1/models

# 推理
curl -X POST http://192.168.10.39:8000/v1/completions \
  -H "Content-Type: application/json" \
  -d '{"model": "Qwen/Qwen2.5-0.5B-Instruct", "prompt": "Hi!", "max_tokens": 50}'

# 流式推理
curl -X POST http://192.168.10.39:8000/v1/completions \
  -H "Content-Type: application/json" \

```

### 停止

```bash
# Kill processes
ssh shuwen@192.168.10.39 'killall neurx-controller'
ssh shuwen@192.168.10.75 'killall neurx-worker'
```

## 🐛 快速故障排查

| 问题 | 解决 |
|------|------|
| Worker 无法连接 | `ssh shuwen@192.168.10.75 'telnet 192.168.10.39 29500'` |
| GPU 不可用 | `ssh shuwen@192.168.10.39 'nvidia-smi'` |
| 模型未找到 | `ssh shuwen@192.168.10.39 'ls /model/'` |
| API 无响应 | `curl http://192.168.10.39:8000/v1/models` |
| 查看错误 | `tail -f /tmp/neurx_cluster/logs/*.log` |
